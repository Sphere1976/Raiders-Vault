# Raiders Vault Platform Roadmap

## Now

- ASP.NET Core MVC application with operational planning workflows.
- Next.js companion console.
- Spring Boot LiveOps service.
- GraphQL BFF scaffold.
- AWS Terraform and CloudFormation.
- Kubernetes, Kustomize, and Helm.
- OpenAPI, Postman, Playwright, JUnit, Cucumber, and k6 artifacts.

## Next

- Replace demo authentication with OIDC.
- Add RBAC across MVC, Next.js, and service APIs.
- Add OpenTelemetry traces and correlation IDs.
- Add container image scanning and SBOM publishing.
- Add persistent production database provider.
- Add EventBridge publisher from MVC audit events.
- Add warehouse ingestion pipeline.

## Later

- Mobile push notifications for live map conditions.
- Real-time updates with SignalR or WebSockets.
- Multi-region AWS deployment.
- Blue/green or canary deployments.
- Feature flags and experimentation.
- Customer-facing SLA dashboard.

## Interview Narrative

Raiders Vault started as a focused MVC product and expanded into a staged modernization program. The
repo now demonstrates how to evolve a working application into a multi-client, multi-service,
cloud-deployable platform while preserving delivery continuity.
