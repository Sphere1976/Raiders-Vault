# Raiders Vault Recruiter One-Pager

## What It Is

Raiders Vault is a full-stack operations intelligence platform for ARC Raiders planning. It combines a
working ASP.NET Core MVC product with modern frontend, Java services, cloud infrastructure, automated
testing, and platform engineering artifacts.

## Technologies Demonstrated

- React, TypeScript, Next.js
- Java, Spring Boot, Spring GraphQL
- ASP.NET Core, C#, EF Core, SQLite
- AWS ECS Fargate, ALB, CloudWatch, EventBridge
- Terraform, CloudFormation, Kubernetes, Helm, Rego
- Playwright, xUnit, JUnit, Cucumber, Postman, k6
- GitHub Actions, CodeQL, SBOM, Dependabot
- Expo/React Native mobile scaffold

## Why It Matters

The project demonstrates both hands-on implementation and architecture judgment:

- It preserves a working product while adding modern services.
- It uses typed contracts and multiple client surfaces.
- It includes quality gates and release governance.
- It documents tradeoffs through ADRs, PRD, runbooks, threat modeling, SLOs, and roadmap.
