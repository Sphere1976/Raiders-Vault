# Raiders Vault Mobile

Expo/React Native companion scaffold for the Raiders Vault platform.

This mobile shell demonstrates how the same Global Ops and LiveOps contracts can support a native
operator experience without rewriting the core MVC application.

## Run

```bash
npm install
npm run start
```

## Why it exists

- Demonstrates cross-platform product thinking.
- Reuses the same operational domain model as the web apps.
- Provides an interview talking point for scaling one backend into multiple clients.
